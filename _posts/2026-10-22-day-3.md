## Grokking Chapter 4 — Quicksort

Quicksort is a **divide-and-conquer** algorithm. The strategy:

1. If the list has 0 or 1 item, it's already sorted. Return it. (base case)
2. Pick an item from the list — call it the **pivot**.
3. Put every item smaller than the pivot into a LEFT pile.
4. Put every item bigger than the pivot into a RIGHT pile.
5. Recursively quicksort each pile.
6. Combine: `quicksort(left) + [pivot] + quicksort(right)`.

I played it by hand on paper first with the list `[22, 8, 47, 15, 3, 31, 19]`. Pivot 31 → everything smaller goes left, 47 goes right. Then on the left pile pivot 19, then 15, then 3 and 8. After four rounds the base case fires everywhere and the list is sorted: `[3, 8, 15, 19, 22, 31, 47]`.

Then I wrote it in Python:

```python
def quicksort(array):
    if len(array) < 2:
        return array # base case
    else:
        pivot = array[0]
        less = [i for i in array[1:] if i <= pivot]
        greater = [i for i in array[1:] if i > pivot]
        return quicksort(less) + [pivot] + quicksort(greater)

print(quicksort([22, 8, 47, 15, 3, 31, 19]))
# [3, 8, 15, 19, 22, 31, 47]
```

Big O: **O(n log n)** on average. Each round does O(n) work splitting into piles, and you do about log n rounds of splitting (because each round roughly halves the work). n × log n = **n log n**. Beats selection sort's O(n²) badly on big lists. 1000 items at O(n²) is 1,000,000 operations; at O(n log n) it's about 10,000.

## Petzold Chapter 4 — Anatomy of a Flashlight

A flashlight has four parts: battery, wire, bulb, switch.

- **Battery** = chemical energy → electrical energy. Pushes electrons.
- **Wire** = conductor. Lets electrons flow. Copper is cheap and works. Silver and gold also conduct but are expensive.
- **Insulator** = blocks electrons. Rubber, plastic, cloth. That's why wires have plastic coating.
- **Bulb** = a wire with high resistance. Electrons squeeze through, heat up, glow.
- **Switch** = opens or closes the circuit. CLOSED = electrons flow = light ON. OPEN = no flow = light OFF.

Petzold introduces Ohm's law: **I = E / R** (current = voltage ÷ resistance). And power: **P = E × I** (watts = volts × amps).

The chapter ends with the whole point: a flashlight is either ON or OFF, with no in-between. **It is a binary device.** Just like Morse (dot/dash), Braille (bump/flat), and binary numbers (0/1). The next chapters are going to use this fact to build an entire computer out of nothing but switches and wires. I noticed that copper, the best cheap conductor, is the same copper I found in my jumper wire this morning for the Metal Lab. Chemistry and circuits are the same substance.
